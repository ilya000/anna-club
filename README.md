# Anna Club — website

Static one-page site for **Anna Club** — fitness workouts, tours and community, led by Anna Prasikova. Domain: [anna.club](https://anna.club).

- Self-contained: plain HTML/CSS/JS, no build step.
- English chrome + Russian content (by design).
- Class schedule and client login are embedded from PTminder.

## Run locally

Any static server, e.g.:

```bash
python3 -m http.server 4191
# then open http://localhost:4191
```

Or just open `index.html` in a browser.

## Deploy

It's static — host anywhere (GitHub Pages, Cloudflare Pages, DigitalOcean, Netlify…). For GitHub Pages, serve from the repository root.
